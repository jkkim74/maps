# 후지모토 모의시험 시작 안내 화면

사용자가 2026-10-22 실제 화면을 확인한 뒤 다음 제안을 승인했다:
예산 확인 → 자동 준비 점검 → 동의·시작 승인 → 진행 확인.

상단에는 현재 단계, 지금 할 행동, 최근 확인 시각을 보여준다. 후보 대기,
운영자 확인 필요, 승인 준비 완료, 시작 예약, 진행, 중지, 만료, 조회 실패를
구분한다. 이미 저장된 총예산과 두 모드의 배분을 명시하고 재저장을 요구하지 않는다.
예산 변경 저장이 신규 진입을 중지시킨다는 설명은 저장 버튼 가까이에 유지한다.

준비 점검에서는 사용자의 예산 설정, 자동 수집/선별/시세 대기, 운영자 계좌/주문
설정 확인을 나눈다. 승인 버튼은 기존 서버 eligible과 명시적 동의가 모두 있어야
활성화된다. 후보 선택과 분할매매는 자동이며 승인 다음 거래일부터 자연 신호로
주문한다는 설명을 표시한다. 진행 중에는 사이클/주문 확인과 신규 진입 중지를 안내한다.

15초마다 화면이 보이는 동안 읽기 전용 상태를 갱신한다. 중복 조회나 진행 중인
쓰기와 겹친 오래된 응답이 화면 상태를 되돌리지 않도록 한다. 조회 실패는 준비
완료 표시와 시작 권한을 제거한다. 작성 중 예산/호가 설정과 명시적 동의를 자동
조회가 임의 변경하지 않으며, 쓰기 성공 뒤 동의 초기화는 기존 동작을 유지한다.

측정 검증 기반 활성화는 기본 닫힌 고급 설정으로 옮기고 모의시험과 별도 경로임을
명시한다. 주요 후보 차단 사유는 한국어로 표시하며 모르는 값은 미확인으로 남긴다.
기존 레이아웃과 의존성을 사용한다. 서버 API/매매 규칙/예산/주문 스위치/승인 상태는
이 UI 변경으로 수정하지 않는다. 실제 시험 시작·매매·청산을 수행하지 않는다.

검증은 실제 inline JavaScript를 실행하는 기존 Node VM 테스트와 실제 브라우저의
격리된 합성 화면으로 진행한다. 합성 결과는 운영 준비나 시험 성과의 증거가 아니다.
