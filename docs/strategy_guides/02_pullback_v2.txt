[자동매매 전략 가이드 #2] 눌림목 매수 V2: 스토캐스틱으로 바닥을 잡는 법

안녕하세요 :)
지난 글에서 눌림목 매수 V3를 소개해드렸는데요,
오늘은 같은 "눌림목"이지만 다른 지표를 쓰는 V2를 소개합니다.
(시스템 안에서는 pullback_v2 라는 이름으로 돌아갑니다)

같은 아이디어라도 재는 자를 바꾸면 결과가 달라집니다.
그래서 저는 둘 다 굴리고, 성적을 따로 관리합니다.


────────────────────
한 줄 요약
────────────────────

  상승 흐름인 종목이 스토캐스틱 기준으로 과매도에 들어왔을 때 사서,
  5일선까지 회복하면 파는 전략입니다.


────────────────────
스토캐스틱이 뭔가요?
────────────────────

이름은 어렵지만 개념은 아주 직관적입니다.

  "최근 N일 동안의 가격 범위에서, 지금 가격은 어디쯤인가?"

이걸 0~100으로 표현한 지표입니다.

예를 들어 최근 9일 동안
  가장 높았던 가격이 11,000원
  가장 낮았던 가격이 10,000원
  이었다고 해봅시다.

  · 지금 가격이 11,000원이면 → 100 (제일 위)
  · 지금 가격이 10,000원이면 → 0   (제일 아래)
  · 지금 가격이 10,500원이면 → 50  (딱 중간)

즉 숫자가 낮을수록 "최근 범위 안에서 바닥 쪽에 있다"는 뜻입니다.

RSI와 비슷해 보이지만 차이가 있습니다.
  · RSI      → 오른 힘과 내린 힘의 비율을 봅니다
  · 스토캐스틱 → 가격의 위치(높낮이)를 봅니다

그래서 V3(RSI)는 "얼마나 세게 밀렸나"를 잡고,
V2(스토캐스틱)는 "얼마나 낮은 자리에 왔나"를 잡습니다.
성격이 미묘하게 다르죠.


────────────────────
언제 사나요? (진입 조건 3개, 모두 만족해야 함)
────────────────────

조건 ①  5일 이동평균선이 30일 이동평균선보다 위에 있다
   → 상승 흐름 확인입니다.
     V3는 20일선을 쓰는데 V2는 30일선을 씁니다.
     조금 더 긴 호흡의 추세를 봅니다.

조건 ②  스토캐스틱 %K(9일)가 25 아래로 내려왔다
   → 최근 9일 가격 범위에서 하위 25% 구간에 왔다는 뜻입니다.
     "충분히 눌렸다"의 기준이죠.

조건 ③  오늘 저가가 어제 저가보다 낮다
   → V3와 동일한 마지막 확인입니다.
     한 번 더 눌린 것을 확인하고 들어갑니다.


────────────────────
언제 파나요? (청산 조건)
────────────────────

  종가가 5일 이동평균선 이상으로 회복하면 매도
  (단, 최소 하루는 보유합니다)

V3가 "5일선을 뚫고 올라가는 순간"만 잡는 것과 달리,
V2는 "5일선 위로 회복하면" 팝니다.
조금 더 빨리, 조금 더 자주 파는 셈입니다.

"최소 하루 보유" 조건이 붙은 이유는,
매수한 당일에 바로 조건이 충족돼 사자마자 파는 일을 막기 위해서입니다.


────────────────────
손절 규칙
────────────────────

  기본 손절: 매수가 대비 -6%

V3(-5%)보다 1%p 넓습니다.
30일선 기준의 조금 더 긴 호흡이라 여유를 더 준 것입니다.

변동성 손절은 ATR의 2배로 V3와 동일합니다.
고정 6%와 ATR 기준 중 더 여유 있는 쪽을 씁니다.


────────────────────
어떤 장세에서 쓰나요?
────────────────────

  선호 장세 : 강세장(strong), 혼조장(mixed)
  사용 안 함 : 약세장(weak)

V3와 같습니다. 눌림목 계열은 하락장에서 위험합니다.


────────────────────
V2와 V3, 뭐가 다른가요?
────────────────────

한눈에 비교해보시죠.

  · 판단 지표
      V3 → RSI(2일)  : 밀린 "힘"을 봄
      V2 → 스토캐스틱(9일) : 밀린 "위치"를 봄

  · 추세 기준선
      V3 → 20일선
      V2 → 30일선 (조금 더 긴 호흡)

  · 매도 시점
      V3 → 5일선 상향 돌파하는 순간만
      V2 → 5일선 위로 회복하면

  · 손절
      V3 → -5%
      V2 → -6%

  · 하락장 차단 필터
      V3 → 있음 (20일선이 한 달 전보다 높아야 함)
      V2 → 없음

마지막 항목이 중요합니다.
V3에는 "이동평균선 자체가 우상향인가"를 보는 국면 필터가 있는데,
V2에는 없습니다.

그래서 V2가 조금 더 공격적이고, 그만큼 횡보장에 약합니다.
제 시스템에서 V3를 주력으로 두고 V2를 보조로 두는 이유입니다.


────────────────────
숫자로 보는 기본 설정
────────────────────

  단기 이동평균     : 5일
  장기 이동평균     : 30일 (조정 범위 20~30일)
  스토캐스틱 기간   : 9일 (조정 범위 5·9·14일)
  스토캐스틱 기준값 : 25 (조정 범위 20~25)
  스무딩            : 3일
  손절              : -6%
  변동성 손절 배수  : ATR × 2.0
  허용 최대낙폭     : 18%
  선호 장세         : 강세 · 혼조


────────────────────
초보자를 위한 체크포인트
────────────────────

  1. 스토캐스틱이 낮다고 무조건 사면 안 됩니다.
     계속 떨어지는 종목은 스토캐스틱이 며칠씩 바닥에 붙어 있습니다.
     반드시 5일선 > 30일선 조건을 먼저 확인하세요.

  2. 같은 아이디어라도 지표에 따라 결과가 달라집니다.
     그래서 "어떤 지표가 최고인가"를 찾기보다
     "여러 개를 나눠서 굴리는" 편이 안전합니다.

  3. V2는 V3보다 자주 사고 자주 팝니다.
     그만큼 수수료와 세금이 더 나갑니다. 이것도 비용입니다.
