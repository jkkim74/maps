### 1. 통신 시험을 먼저 분리

1. `MAPS_KIS_PAPER_MIN_INTERVAL_SECONDS=1.1`만 시험한다(이전 0.55).
   지수 REST 5초/WS OFF, connect/read/order timeout 3/8/30초 유지.
2. 장중 재기동하지 않는다. 장마감 이후 미체결·상한가 보유/정산과 cron 실행 상태를
   확인하고 `.env`를 권한 600으로 백업한 뒤 적용한다. 16:00~16:45 배포 금지.
   같은 계좌를 사용하는 다른 전략의 동기화/청산도 확인한다.
3. 재기동 실패·헬스 실패 시 이전 설정과 커밋을 복원한다. 설정 파일 내용·키는 로그에
   출력하지 않는다. 운영 tracked 파일이 수정돼 있으면 덮어쓰지 않는다.
4. 다음 정규장 전체로 호출 제한 비율 <1%, broker_sync 완료 간격 p95 ≤120초,
   청산·정산 장애 없음을 확인한다. 중간 표본만으로 합격하지 않는다.
   호출 간격 증가로 감시 지연이 악화되면 0.55로 복원한다. 기준 미달이면 강도 완화를
   중단하고 호출 경합·스캔 지연을 조사한다. 타임아웃 연장으로 덮지 않는다.

### 2. 계측과 130 적용

```bash
cd /opt/maps
.venv/bin/python -B -m scripts.limit_up_cross_samples_report 2026-09-21 \
  --logs 'logs/maps.log*' > /tmp/limit-up-gates.json
```

출력은 JSON으로 변경됐다. `comparisons.groups`는 날짜·실행 모드·가드 전후를 분리한다.
`unknown_guard_timing`을 통과로 세지 않는다. 다른 일일 가드의 시각을 복원할 증거가
없어도 unknown이다. 코스닥 이전 표본 역시 transient 피드 잠금·현금·슬롯을 검증한
실주문 후보가 아니다. `log_evidence.health`는 계좌 전체 요청 시도와 동기화 간격이다.

`--verified-day YYYY-MM-DD`는 해당 날짜 09:10~14:30 전체 엔진/피드 가동을 로그로
확인한 경우에만 반복 지정한다. 재기동·기동 지연·데이터 공백은 별도 감사한다.
표본 누락, 세션당 200건 상한, 진행 중인 날은 지정해도 검증일수에 포함하지 않는다.
감시 세션 자체가 없는 날은 이 리포트로 검증하지 않는다. `ten_day_evidence_available`
역시 설정 변경 승인이 아니며 자동으로 강도를 바꾸는 기능은 없다.

10거래일과 통신 기준을 충족하면 모의계좌임을 확인한 후 환경변수
`MAPS_LIMIT_UP_MIN_EXECUTION_STRENGTH=130`으로 별도 적용하고 재기동한다.
기본은 150, 하한은 130이며 NaN/Infinity를 거부한다. 상태 API의
`min_execution_strength`/`min_turnover_krw`로 실제 적용값을 확인한다(엔진 OFF는 null).
추가 10거래일 주문 접수·체결·취소·청산·정산과 비용 반영 손익을 기록한다. 주문이 없으면
검증 부족으로 남기며 기준을 자동으로 더 낮추지 않는다.

중복 주문·보호청산·정산 문제 시 신규 진입만 중단하고 강도 150으로 복원한다.
보유분 청산 경로는 유지한다. 실계좌 전환·손실 한도 변경·가드 해제는 하지 않는다.

## 해석 시 주의

- **표본이 이틀치, 9/21 은 반나절**이다. 임계값 확정에는 부족하다 — 최소 1~2주 더 쌓는다.
- `cross_samples` 는 세션당 **200건 상한을 넘으면 버린다**(앞을 밀어내지 않음). 223250 처럼
  재돌파가 많은 세션은 장 후반이 빠질 수 있다.
- 9/21 표본은 배포(13:04) 이후만 있다. 그날 오전 교차는 없다.
- 관측 전용(`observe_only`, 상장 100일 미만) 세션은 9/22 표본에 없다(386380 오늘 미교차).
  나오면 `failed == ""` 로 게이트 통과 사실이 남으니 별도 집계할 것.
- 표본 분포는 **강세 개장(9/22 는 장 초반 표본)** 편향이 있을 수 있다. 오후 표본과 나눠 볼 것.

## 하지 말 것 / 이미 반증된 것

- "래치 때문에 표본이 장 초반에 쏠렸다" 가설 — 9/21 반증(교차마다 재평가함).
- 임계값 낮추기 전에 `ge=` 하한을 조용히 풀지 말 것 — 하한은 유동성 사고 방지용이라 근거와

- 강도만 낮추고 거래대금은 유지하는 방향이 데이터상 우선이다. 둘 다 동시에 바꾸면 무엇이
